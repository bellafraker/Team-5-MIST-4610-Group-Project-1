## Problem Description
The task is modelling and building a relational database for the operations of Athens Pulse Fitness, focusing on coordinating members, trainers, classes, and studio rooms. The database manages memberships, trainer assignments, class scheduling, and attendance while maintaining clear relationships between all entities. It enforces key business rules, including room capacity limits and membership tier restrictions, such as limiting Basic members to four classes a month while Unlimited members have unrestricted access. Attendance tracking must also ensure members are marked as “No-Show” if they fail to check in at least five minutes before class begins. The finished system supports meaningful business insights, member attendance trends, and facility usage efficiency.
